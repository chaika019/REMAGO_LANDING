# Проверка сглаживания текста — 11 октября 2026

Проверены CSS страницы FAQ, общих контейнеров и остальных страниц. У статичного FAQ и его родителей нет `scale()`, `translateZ`, `translate3d`, `will-change: transform` или `filter`. Поэтому конкретная причина цветных краёв на неподвижном FAQ пока не подтверждена.

## Изменения

- Центрирование карточек каруселей переведено с процентных трансформаций на наложение элементов CSS Grid. Ширина, высота, пропорции и типографика сохранены.
- Из анимаций каруселей удалены `translate3d` и постоянные `will-change`; остался переход через `translateX` и прозрачность длительностью 400 мс. После перехода трансформация отсутствует.
- Удалено перемещение текста при наведении на общие кнопки, карточки контактов, категории FAQ и кнопку карты. Тени и цвета наведения сохранены.
- У RTV удалены perspective внешней карточки с подписями и постоянный `will-change` внутреннего блока. Perspective самой кнопки переворота сохранена для работающего flip.
- Добавлены `-webkit-font-smoothing: antialiased` и `-moz-osx-font-smoothing: grayscale`. По [документации MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-smooth) эти нестандартные свойства действуют только на macOS. Они не гарантируют исправление сглаживания на Windows/Linux; на macOS текст может выглядеть тоньше без изменения размеров шрифта.

Оставшиеся фильтры относятся к изображениям и декоративным значкам; масштабирование — к декоративным элементам. Принудительные GPU-слои и трюки с почти единичной прозрачностью не добавлены. Адаптивные размеры и межстрочные интервалы не округлялись: дробные значения сами по себе не подтверждают причину дефекта, а их изменение нарушило бы заданную типографику.

## Проверка

- `npm run typecheck`, `npm run build` и `npm run check:carousels` проходят; восемь проверок логики каруселей успешны.
- Разбор шести изменённых CSS-файлов подтверждает сохранение деклараций шрифтов, межстрочных интервалов, размеров, пропорций, отступов и цвета текста.
- Серверная разметка девяти маршрутов до/после идентична. Проверены 101 использование локальных изображений. Серверный рендер не проверяет взаимодействия карты Leaflet.
- Проверка браузером при zoom 100% не выполнена: Vite не может открыть порт (`listen EPERM`), Chromium завершается до создания страницы (`crashpad: setsockopt: Operation not permitted`). Визуальное исчезновение артефактов и фактическая геометрия после замены центрирования остаются непроверенными.

Для окончательного подтверждения нужно открыть FAQ при zoom 100% в браузере, где проявляется дефект, и сравнить неподвижный текст и текст во время переходов. Запрошены браузер и ОС пользователя; на момент проверки ответ не получен.
