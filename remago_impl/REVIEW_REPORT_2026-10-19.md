Сверены локальные экспорты с текущими компонентами и CSS. Исправлены проблемы навигации, модальных окон и семантики. Полная визуальная приёмка desktop/mobile остаётся незавершённой: запуск сервера заблокирован системой (`listen EPERM`), поэтому скриншоты реализации и pixel diff не получены.

- Дополнения последних проходов (индивидуальные борды, видео RTV, фотографии 25 адресов, статичная карта Яндекса) сохранены. Новый наружный борд включает маскота; старую коррекцию отступов для прежнего изображения к нему не возвращали.
- Это сверка структуры, содержимого и исходников. Фактические переносы строк, наложения на разных размерах, плавность, hover/tap, восстановление фокуса браузером и визуальное качество уменьшенных файлов требуют живого браузера.

## Исправления

- Мобильное меню закрывается по Escape с возвратом фокуса на кнопку, по клику снаружи, после выбора текущей страницы и при переходе к desktop. Высота ограничена экраном, содержимое можно прокрутить в landscape. Учтён реальный breakpoint меню 1050 px. Закрытое меню уже имело `display: none`; дополнительное скрытие не требовалось.
- Добавлены переход к основному содержимому и заметный клавиатурный фокус, включая кнопку видео RTV, у которой старое правило убирало outline.
- У RTV появился скрытый H1 без изменения визуальной композиции. Точки выбора рекламных адресов объявляют текущий адрес через `aria-current`.
- Блокировка прокрутки общая для видео и форм: закрытие одного окна больше не восстанавливает прокрутку, пока другое остаётся открытым. Проверено по жизненному циклу эффектов; браузерное воспроизведение недоступно.
- Неактивная кнопка языка заменена индикатором русского языка. Три пустых якоря документов заменены почтовым запросом нужного документа с поясняющей доступной подписью. Самих документов в материалах нет; публикация юридических текстов остаётся внешней зависимостью.
- Обработка стрелок карусели не перехватывает ввод в полях/редактируемом содержимом.

## Оптимизация

В manifest зарегистрированы 82 новых изображения с размерами; создано 138 WebP-вариантов шириной 384/640 px. Оригиналы остаются доступны для больших экранов. Уменьшенные версии используют Lanczos и quality 90, поэтому не являются побитовой копией оригиналов. `AssetImage` и предварительная загрузка используют одинаковые `sizes`; для партнёров и индивидуальных бордов они учитывают ширину карточки. Соседние адреса подготавливаются только при приближении к секции.

Расчёт выбора файлов при 390 px / DPR 2, без сетевого замера:

CSS gzip — 27,90 → 28,05 kB. Ускорение в секундах не измерено. Расчёт сохранён в `reports/review/2026-10-19-assets.json`.
